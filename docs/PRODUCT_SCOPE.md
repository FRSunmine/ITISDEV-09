# SideQuest MVP scope

## Product statement
SideQuest is a campus-focused micro-freelancing platform connecting verified student freelancers with student organizations, university departments, startups, and small businesses needing short-term services.

## Core outcomes
- Students discover quests, apply, manage work, submit deliverables, receive feedback, and build verified portfolio entries.
- Clients create structured quests, define binary deliverables, compare applicants, monitor work, and approve outputs.
- Administrators verify users, review reports, and monitor operational analytics.

## Implemented MVP scope
- Role-based registration, login, logout, sessions, and route authorization
- Student academic profile submission and administrator verification
- Student dashboard, quest discovery, details, applications, and status tracking
- Dedicated student application history and persisted quest conversations
- Client dashboard, transactional quest creation, and applicant decisions
- Student and client quest workspaces with deliverable review states
- Quest completion, participant reviews, and verified portfolio entries
- Administrator verification, account controls, and persisted analytics
- SQLite persistence for users, profiles, quests, applications, conversations, messages, deliverables, reviews, and sessions

## Explicitly out of scope
- Payment processing or escrow
- AI matching, RAG, or MCP actions
- Blockchain or cryptographic credentials
- Mobile-native application
- Real-time chat, sockets, file storage, or notifications
- Password reset and outbound email
- Multi-university deployment
